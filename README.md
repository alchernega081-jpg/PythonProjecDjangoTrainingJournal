Веб-приложение
"Журнал обучения"

Цель проекта
Создать онлайн-журнал (веб-приложение), который позволяет пользователям записывать темы, которые они изучают, и добавлять записи (entries) по мере продвижения в изучении каждой темы .
⚙️ Основной функционал (Спецификация)

Приложение должно поддерживать следующие возможности:
    Управление темами (Topics):
        Пользователь может создавать новые темы для изучения (например, «Python», «Django», «JavaScript»).
        Список всех тем отображается на отдельной странице.
        Каждая тема belongs to (принадлежит) конкретному пользователю (после реализации системы аккаунтов).

    Управление записями (Entries):
        Внутри каждой темы пользователь может добавлять записи (текст, описывающий, что он узнал).
        Записи отображаются в хронологическом порядке (сначала новые) на странице темы.
        Каждая запись содержит текст и дату добавления.

    Система аккаунтов (User Accounts):
        Регистрация новых пользователей.
        Вход и выход из системы.
        Каждый пользователь видит только свои темы и записи (данные изолированы).

    Администрирование:
        Настройка панели администратора Django для управления темами и записями.

🛠️ Технологический стек (по книге)
    Язык: Python.
    Фреймворк: Django.
    База данных: SQLite (по умолчанию в Django).
    Фронтенд: HTML, CSS, Bootstrap (для стилизации) .
    Тестирование: В новых изданиях используется pytest для написания тестов .

📂 Примерная структура проекта
Согласно книге, проект обычно организуется следующим образом:
    learning_log (корневая папка проекта).
        learning_logs (основное приложение).
            models.py (Модели Topic и Entry).
            views.py (Логика отображения страниц).
            urls.py (Маршруты).
            templates/learning_logs/ (HTML-шаблоны).
        users (приложение для управления аккаунтами).
        manage.py (управление проектом).
